# CPE2600 Vector Calculator

## Description
This program is a vector calculator written in C.
It performs mathematical operations on vectors and
supports storing vectors using dynamic memory.

## Building the Program
- Open a Linux terminal.
- Navigate to the project folder.
- Run `make`.

## Running the Program
Run the executable created by the Makefile.

## Supported Commands
- Help
- Vector addition
- Vector subtraction
- Dot product
- Cross product
- Save vectors to CSV
- Load vectors from CSV
- Quit

## Dynamic Memory
The program uses dynamic memory to store vectors
during execution. Allocated memory is released
when it is no longer needed to prevent memory leaks.
